给冲动也加个冷却

就像游戏里的技能一样，给消费和行为设定一段等待时间。外卖三天一次，买衣服两周一次。用过之后，圆环会慢慢充满，直到你可以再次使用。

🍔

使用方法

创建冷却

设定名称、表情符号和等待时间（小时、天、周、个月）。餐饮、购物、娱乐、健康、金融等常用项目，可在推荐模板中一键添加。

使用

使用时点按使用，冷却就会重新开始。你还可以记下使用原因和实际花费。如果在冷却期间使用，这一点也会被记录下来。

结束时通知

冷却结束时会通过通知提醒你。在主屏幕小组件上，可以直接查看现在能用的项目和剩余时间。

统计

显示你遵守冷却的程度（遵守率）、各类别的记录、打破冷却的次数，以及填写了预计花费的项目本月节省的金额。

记录只保存在你的设备里

没有账号，也没有广告。冷却和使用记录只保存在你的 iPhone 中，不会发送给开发者。发送给开发者的只有匿名使用统计、错误报告，以及你主动提交的反馈。详情请见隐私政策。
