개인정보 처리방침

앱: 쿨타임 · 시행일: 2026년 10월 8일

요약. 쿨타임은 회원가입이 없고, 광고·추적·분석 도구를 쓰지 않습니다. 쿨타임 항목과 사용 기록은 사용자의 기기 안에만 저장됩니다. 개발자에게 전달되는 것은 사용자가 직접 보낸 피드백뿐입니다.

1. 기기에 저장하는 정보

앱이 다루는 다음 정보는 iPhone 안의 앱 저장소에만 보관되며, 개발자의 서버로 전송되지 않습니다. 개발자는 서버를 운영하지 않습니다.

  • 사용자가 만든 쿨타임 항목: 이름, 이모지, 카테고리, 쿨타임 기간, 예상 비용
  • 사용 기록: 사용한 시각, 적어 넣은 메모, 실제 비용, 쿨타임 중 사용 여부
  • 위의 기록으로 계산한 통계(준수율, 절약 금액 등)
  • 홈 화면 위젯이 보여 줄 요약 — 기기 안의 앱 그룹 공간에 저장되어 위젯만 읽습니다

앱을 삭제하면 이 정보도 함께 삭제됩니다. 앱 안에서 항목을 지우면 그 항목과 기록이 지워집니다.

2. 알림

알림을 허용하면 쿨타임이 끝나는 시각에 기기 안에서 예약한 로컬 알림을 보냅니다. 알림을 위해 외부로 보내는 정보는 없으며, 허용하지 않아도 앱의 다른 기능은 그대로 쓸 수 있습니다.

3. 피드백 보내기

설정의 피드백 보내기로 의견을 보내면(앱이 만족도를 물었을 때 이어서 보내는 경우 포함), 다음 정보가 Apple의 iCloud(CloudKit) 저장소를 거쳐 개발자에게 전달됩니다.

  • 사용자가 적은 내용: 의견 유형, 메시지, 첨부한 스크린샷
  • 회신용 이름·이메일 — 적었을 때만 전송되며, 비워 두면 기록되지 않습니다
  • 앱 버전, 기기 종류, iOS 버전, 언어 설정

피드백은 답변과 앱 개선에만 쓰며, 다른 회사에 넘기지 않습니다. 보내지 않으면 아무것도 전송되지 않습니다. 피드백을 보내려면 iCloud 로그인이 필요하고, 원하면 이메일로 보낼 수도 있습니다. 보낸 피드백의 삭제를 원하면 아래 문의처로 알려 주세요.

4. 수집하지 않는 것

  • 계정, 이름, 전화번호 — 로그인 자체가 없습니다 (피드백에 직접 적은 회신처만 예외)
  • 위치, 연락처, 사진 보관함, 카메라, 건강 정보 — 접근하지 않습니다
  • 광고 식별자, 추적, 제3자 분석·광고 SDK — 쓰지 않습니다
  • 쿨타임 항목·사용 기록·금액 — 개발자에게 보내지 않습니다

5. 아동의 개인정보

쿨타임은 아동을 대상으로 하지 않으며, 아동의 개인정보를 따로 수집하지 않습니다.

6. 방침 변경

방침이 바뀌면 이 페이지를 고치고 위의 시행일을 갱신합니다. 데이터를 새로 보내게 되는 변경은 앱 업데이트 안내에도 함께 적습니다.
