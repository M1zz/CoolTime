プライバシーポリシー

アプリ: クールタイム · 施行日: 2026年10月16日

概要。 クールタイムは会員登録がなく、広告・トラッキングツールや他社の分析ツールを使用しません。クールタイムの項目と使用記録は、お客様の端末の中にだけ保存されます。開発者に届くのは、アプリを改善するための匿名の利用統計・エラーレポートと、お客様がご自身で送信したフィードバックだけです。

1. 端末に保存する情報

アプリが扱う次の情報は、iPhone 内のアプリの保存領域にのみ保管され、開発者のサーバーには送信されません。開発者はサーバーを運用していません。

  • お客様が作成したクールタイムの項目: 名前、絵文字、カテゴリ、クールタイムの期間、予想金額
  • 使用記録: 使用した日時、入力したメモ、実際の金額、クールタイム中に使用したかどうか
  • 上記の記録から計算した統計（達成率、節約額など）
  • ホーム画面のウィジェットに表示する概要 — 端末内のアプリグループの領域に保存され、ウィジェットだけが読み取ります

アプリを削除すると、これらの情報も一緒に削除されます。アプリ内で項目を削除すると、その項目と記録が削除されます。

2. 通知

通知を許可すると、クールタイムが終わる時刻に、端末内で予約したローカル通知を送ります。通知のために外部へ送信される情報はなく、許可しなくてもアプリのほかの機能はそのまま使えます。

3. フィードバックの送信

設定のフィードバックを送るから意見を送信すると（アプリが満足度をたずねた際にそのまま送信する場合を含みます）、次の情報が Apple の iCloud（CloudKit）ストレージを経由して開発者に届きます。

  • お客様が書いた内容: 意見の種類、メッセージ、添付したスクリーンショット
  • 返信用のお名前・メールアドレス — 入力した場合にのみ送信され、空欄のままなら記録されません
  • アプリのバージョン、デバイスの種類、iOS のバージョン、言語設定

フィードバックは返信とアプリの改善にだけ使用し、他社には提供しません。ご自身で送信しない限り、フィードバックは送信されません。フィードバックの送信には iCloud へのサインインが必要で、ご希望であればメールで送ることもできます。送信したフィードバックの削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。

4. 匿名の利用統計

何人が使っているかを把握し、エラーを修正するため、クールタイムは次の匿名統計を Apple の iCloud（CloudKit）に送信します。開発者のみが閲覧します。

  • インストール時に作成されるランダムな ID — 端末、Apple ID、ほかのアプリとは紐づかず、再インストールすると変わります
  • アプリのバージョン、iOS のバージョン、地域・言語設定
  • アプリを開いた回数と日、インストールした日付とインストール後の経過日数
  • 満足度の質問が表示されたか、フィードバックを送信したかといったアプリ内のイベント — 送信した内容は含まれません
  • アプリが停止したり異常終了したりしたときの診断レポート — アプリのバージョン、iOS のバージョン、デバイスの種類、エラーの技術的な詳細

お名前、連絡先、位置情報、クールタイムの項目・使用記録・金額などのユーザーコンテンツは含まれません。端末が iCloud にサインインしている場合にのみ送信されます。

5. 収集しないもの

  • アカウント、お名前、電話番号 — サインイン自体がありません（フィードバックにご自身で書いた返信先のみ例外です）
  • 位置情報、連絡先、写真ライブラリ、カメラ、ヘルスケア情報 — アクセスしません
  • 広告識別子、トラッキング、他社の分析・広告 SDK — 使用しません
  • クールタイムの項目・使用記録・金額 — 開発者に送信しません

6. お子様の個人情報

クールタイムはお子様を対象としておらず、お子様の個人情報を意図して収集することはありません。

7. ポリシーの変更

ポリシーが変更された場合は、このページを修正し、上記の施行日を更新します。新たにデータを送信することになる変更は、アプリのアップデート情報にも記載します。
