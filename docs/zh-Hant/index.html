給衝動也加個冷卻

就像遊戲裡的技能一樣，為消費與行為設定一段等待時間。外送三天一次，買衣服兩週一次。使用之後，圓環會慢慢充滿，直到你可以再次使用。

🍔

使用方式

建立冷卻

設定名稱、表情符號和等待時間（小時、天、週、個月）。餐飲、購物、娛樂、健康、金融等常用項目，可在推薦範本中一鍵新增。

使用

使用時點一下使用，冷卻就會重新開始。你還可以記下使用原因和實際花費。如果在冷卻期間使用，這一點也會被記錄下來。

結束時通知

冷卻結束時會用通知提醒你。在主畫面的小工具上，可以直接查看現在能用的項目與剩餘時間。

統計

顯示你遵守冷卻的程度（遵守率）、各類別的記錄、打破冷卻的次數，以及填寫了預估花費的項目本月省下的金額。

記錄只存在你的裝置裡

沒有帳號，也沒有廣告。冷卻與使用記錄只儲存在你的 iPhone 中，不會傳送給開發者。傳送給開發者的只有匿名使用統計、錯誤回報，以及你主動送出的意見回饋。詳情請見隱私權政策。
